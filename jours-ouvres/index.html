Jours fériés dans la période (exclus du calcul)

    Jours ouvrés = jours calendaires hors samedis, dimanches, et jours fériés (si l'option est cochée). Les jours fériés mobiles (Pâques, Ascension, Pentecôte) sont calculés par formule, valable pour n'importe quelle année. La Réunion ajoute le 20 décembre (Fête Kaf, abolition de l'esclavage), qui n'est pas férié en métropole.
